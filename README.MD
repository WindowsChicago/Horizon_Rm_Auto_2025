# Horizon_Rm_Auto:

##### by ZYL

#### Horizon战队2025赛季通用自瞄程序，支持全车型，由yaml和宏选择不同模式和调节参数，装甲板识别使用YOLOX神经网络模型+TensorRT加速推理，打符使用传统视觉，支持NX/AGX/NANO

#### 开发记录：

##### Milestone阶段：

**M1：**创建了多个cmakelist，用于nx，x64电脑两种
**M2：**加入了用于程序自启动和nx风扇满速的sh文件,修改了通信包头包尾
**M3：**推理了适用于不同gpu的engine文件，并集成了对应的trtexec文件
**M4：**添加了显示参数，为每个cpp文件单独添加了解读文件
**M5：**解决了卡尔曼滤波反复重启的问题和大恒相机由于时钟错误无法启动预测程序的问题
**M6：**添加了海康相机的驱动支持，同时拆分x64版的cmakelist
**M7：**引入了一组全局变量以解决海康模式在nx上运行时无法绘制装甲板识别线的问题
**M8：**将M7的全局变量改为数组，并修复了在nx上使用海康相机的装甲板号无法显示的问题，同时将相机类型选择和是否显示图形界面的设置移回common.h，并重新规划了param文件夹下的参数用处
**M9：**加入每个线程cpu核心锁定功能，可以部分提升程序在nx上运行的帧数，但由于存在有可能无法正常绑定核心和单个核心占用过大的问题，故设为可选选项并默认不启用，此为里程碑阶段的最后一个Build

##### Release Candidate阶段：

**RC1：**加入英雄自动开火功能（老代码的is_fire和is_hit合并），彻底拆分装甲板四角显示和中心显示，将海康的nx显示修复部分代码移动至邻近推理部分，用来解决使用海康相机时预测点严重漂移问题
**RC2：**找出nx上海康相机无法正常使用的根本原因，彻底解决了海康相机的全部问题，移除了之前的曲线救国措施，重新统一装甲板四角显示和中心显示，并引入了current_location以解决白点紧跟红点而不跟随装甲板中心的问题，同时将神经网络模型选择加入common.h，最后修改了predict.hpp里导致红点异常飞行的代码问题
**RC3：**清理简化了部分无用代码，加入了来自步兵的失帧补偿功能（可选）和图形显示装甲板大小和存在与否的功能，并将不同相机畸变的选择加入common.h，将程序自启动和nx风扇满速的sh文件合并为一个文件，加入反陀螺自瞄功能（可选），对部分待验证稳定性的代码在common.h中采用stable和test来控制，彻底废除了parameter.yaml里的所有参数，有效的参数控制全部移动到common.h，添加了新哨兵的机械偏置值，修复了计算机械偏置的bug
**RC4：**通信上加入了达妙新NX载板的支持，在common.h中加入了弹道中心矫正角度参数控制，用来微调弹道偏角，将神经网络参数改为老英雄的参数，修复了禁用图形界面后无法正常编译的问题，彻底删除了parameter.yaml，加入手动单帧调试模式和时间同步功能以及屏蔽冗余代码功能,修复了英雄自动开火功能的异常
**RC5：**加入步兵自动开火和整车估计功能(实验性功能，目前存在问题，功能未完成),加入了飞机的机械偏置和飞机的通信模式，重写了部分通信代码，发现了红点的异常静止问题和通信异常问题
**RC6:**重写了thread.cpp,修复了红点的异常静止问题和图像显示无法完全禁用且禁用后存在的性能问题，废除了Stable和Test模式，修改了飞机在未找到装甲板时的通信方式，添加了显示上一帧率和红白点自动消失的功能，添加了视频内录功能，添加了哨兵弹道校正角度，添加了发送预测值和当前值的选项，加入了通信数据锁,添加了迈德相机的自动曝光模式
**RC7:**加入了串口通信版步兵的通信支持，添加了25新英雄的机械偏置，添加了哨兵的yaw轴pid校正功能，可执行文件改名为rm_auto，删除了大量无用旧代码（包括无用的EKF.h和EKF.CPP），合并模型文件夹
**RC8:**修复了预测点斜向乱飞的问题，废除了哨兵的yaw轴pid校正功能，加入了显示yaw方向速度功能，改进了自启动脚本的串口赋权机制，默认给所有兵种的0与1串口赋权以防止缺少串口赋权,通信上增加了包头尾自适应功能，大幅简化了common里的接口逻辑和数量,同时大幅削减了程序体积,加入英雄射击测试极简版程序模式，启用时仅有调用相机画准心绿线功能
**RC9:**修复了陀螺模式和飞机模式的预测值异常漂移问题，添加了debug.yaml来控制变化参数，将common中的变化参数移动至此，并加入失帧数值和最小二乘法速度缓存数值控制
**RC10:**加入了40系显卡和Ubuntu22的支持，初步修复出现异常白点的问题,哨兵修改为新版通信方式，合并了飞机支线的代码
**RC11：**重构大部分代码，修改了程序文件架构，修复了时间同步的bug和禁用时间同步无法自动开火的问题，加入新版自瞄代码，修复白点与绿线分离的问题，同时引入新旧两种相机调用方式进行调试,加入通信状态，反陀螺，时间信息的显示，简化了终端的显示输出
**RC12:**对重构的代码进行debug和功能验证，再次修改程序文件架构，迁移相机画准心绿线功能到新写的相机驱动测试程序里，改进了图形界面显示，单独拆分了反陀螺功能，合并了部分重构代码和旧代码，修复了海康相机无法加载配置文件的问题，加入了目前测出的英雄和哨兵的弹道矫正参数
**RC13：**大幅修改通信代码，将包头尾控制引入debug.yaml（经测试发现存在问题不生效）,对于串口步兵出现在使用pc通信的将cd dc篡改成ed fc的问题（nx不会篡改头尾，但是会出现吞噬0x13的问题），加入了自凋零机制，加入了自适应串口名称和输出串口所有信息的功能，将模型选择移动到debug.yaml中，加入哨兵新版坐标系支持，加入串口步兵的nx的自启动和编译支持，加入新版英雄和麦轮步兵的机械偏置
**RC14：**修复了V2版NX的自启动脚本中的问题，修改了哨兵新坐标系的转换机制，删除了大量预测部分大量无用和存在问题的代码,加入了yaw轴L1L2L3三级限制锁以修正在相机识别边缘的速度异常过大的问题，精简了通信模式的选择，修复了飞机和英雄的current点的异常漂移问题，初步设计了修复英雄边缘预测异常的问题的解决办法
**RC15：**加入边缘追踪机制，在边缘上暂缓预测使车快速追踪到装甲板，在合适区域内再进行预测，以解决预测飘移导致无法追踪装甲板的问题，删除大量无用接口，部分RC14中删除的功能回归（以Test模式），引入多个新参数以精细调参，正式启用英雄和哨兵的自动开火功能，删除了新版通信模式（存在问题）,此为RC阶段最后一个build

##### Release to Manufacturing 阶段：

**RTM1：**修改程序文件名称为Rm_Auto,修改了模型文件夹结构以削减程序体积，将串口通信版程序和视控一体版程序合并到主线，修改了程序文件架构，加入了新版步兵的机械偏置和RMUL的一些参考参数,加入了对通用相机的支持,分别为英雄和视控一体步兵单独加入了新版自动开火功能
**RTM2：**将视控一体通信的识别标志和开火标志拆分为两个标志位，引入了新版反陀螺模式，精简CMakeLists，加入新版弹道结算机制，多弹速获得方法，修改自动开火为普通开火和反陀螺开火，引入采集模式，删除部分无用冗杂代码，引入新坐标系转换功能，同时此版本为飞镖视觉的基底版本
**RTM3：**引入了新版麦轮步兵的机械偏置,简化run_current以提升性能,修复了终端因引入run_current而导致的混乱输出,修改了cmakelists以准备引入NT内核，此为RTM阶段最后一个Build

##### New Technology 阶段：

**NT M1：**引入了新版NT预测内核，重写了cmakelists以修复新内核的异常-nan速度问题，合并了大量新旧内核的共用代码，修改了thread读取yaml的方法，修复了使用resize导致的异常性能损失问题
**NT M2：**合并新旧内核大量接口，修复新内核无法显示预测点的问题，修复新内核通信异常的问题，解耦和新旧内核和两种通信，修复旧内核模式下非预测点数据异常-nan的问题,为新内核引入UI界面，修复了串口通信模式下的时间同步问题
**NT M3：**引入打符子程序，提升C++要求到C++14/17，为打符子程序引入原版相机畸变引用和收发数据对接接口，解决了新旧内核和打符子程序之间的兼容问题，优化通信，发现视控一体下的通信问题，修复旧内核run_current的异常问题
**NT M4：**重写内录功能，修复在部分nx上无法正常录制并导致相机崩溃的问题，分离UI绘制和图像显示，以适应部分车不关闭图形界面同时录制无UI素材的需求，修复打符UI问题，修复视控一体弹速无法传入predict的异常问题，引入新版反陀螺
**NT M5：**完成新版反陀螺设计，删除大量老反陀螺的无用逻辑，修改了CmakeLists的书写方式，修改了相机驱动的调用方法，不同电脑不用再修改CmakeLists的相机驱动部分，合并了NX的几个CmakeLists,引入可以在桌面一键打开程序的脚本，修复了海康相机错误的参数传入导致相机变暗的问题，读取视频调试的功能回归，加入对jetson orin系列的支持，新增纯追踪模式，纯预测模式
**NT M6：**新增OpenVINO推理模式，从而支持全部类型设备运行程序，无需cuda依赖,修改了部分文件架构，更加模块化,修改debug.yaml名称为aim_config.yaml
